NE ME CROYEZ
PAS.

Vous avez raison de vous méfier d'un outil qui touche à des vidéos de gens. Tout se vérifie. Allez-y.

Ce que fait NOFACE

  • Sur votre téléphone. La vidéo est analysée dans le navigateur. Elle ne part nulle part.
  • Un carré noir plein. Peint sur l'image avant qu'elle soit réenregistrée. Le visage n'est pas flouté : il n'est plus dans le fichier.
  • Le style ne change rien. Rond, 444, émoji ou image : un fond opaque couvre toute la case avant le décor. Une image transparente laisse voir du noir. L'image choisie ne quitte pas l'appareil.
  • Plaques, en option. Cochez « Masquer aussi les plaques » : rectangle noir, toujours. Le modèle est chargé avec la page, rien ne part ensuite.
  • Sans traces. Le lieu, la date et le modèle du téléphone, souvent cachés dans le fichier, sont retirés.
  • Sans compte. Pas de publicité, pas de mesure d'audience. Comme pour tout site, l'hébergeur (GitHub Pages) voit qui se connecte. Jamais les vidéos.

Sans rien installer

1

Le mode avion

Ouvrez NOFACE, attendez le chargement, passez en mode avion. Masquez une vidéo, enregistrez-la : tout marche sans réseau. Rien ne peut donc partir.

2

Le résultat

Avant de publier, regardez la vidéo masquée en entier. Image par image là où il y a du monde.

Si vous savez coder

  • Code public. NOFACE est une version modifiée de Vesky (github.com/Nctrn17/vesky), sous licence libre AGPL-3.0. Son code : github.com/FR44K-ll/noface. Le site sert les fichiers tels quels, lisibles, sans rien de caché.
  • Aucune trace du visage. test/test-sans-trace.mjs prend deux vidéos identiques sauf les visages et leur pose les mêmes masques : les fichiers produits sont identiques octet pour octet. Aucun filigrane ne peut permettre de retrouver le visage.
  • Aucun envoi. La page interdit au navigateur de se connecter à un autre site que le sien (Content-Security-Policy).
  • Bibliothèques d'origine. ONNX Runtime et Mediabunny : test/verifier-tiers.sh vérifie qu'elles sont identiques aux versions officielles. Le modèle de détection est YuNet, réentraîné par Vesky pour mieux voir la nuit : sa recette est publique. Les plaques : YOLOv9-t d'open-image-models (licence MIT). test/test-masques.py vérifie qu'aucun style ne laisse passer un pixel du visage.

Ce que NOFACE ne fait pas

Je ne trouve pas tous les visages. Un profil, un visage à moitié caché ou très petit peut m'échapper. Touchez l'image pour ajouter un masque à la main.

Les plaques lointaines, de biais ou dans le noir peuvent m'échapper aussi.

Le carré cache le visage. Pas les vêtements, les tatouages, la démarche, le lieu ni la voix. Le son est gardé par défaut : coupez-le avec le bouton « Son ».
